# Imágenes de SM EXTREME LIFE

- `cover.png`: portada del proyecto.
- `reunion-cliente.jpg`: foto de la reunión con el cliente. Aparece en «Resultado y Galería» como evidencia de la etapa actual.

También se admiten las extensiones `.jpeg`, `.webp` y `.png` para ambos nombres. Usa una sola imagen por nombre y conserva su formato real.

Mientras falta la portada, se muestra `cover-pending.svg`: una portada de texto con el nombre y el estado del proyecto, no una captura de una aplicación terminada.

Después de añadir imágenes, vuelve a compilar y desplegar. Si el servidor local no detecta los archivos nuevos, reinícialo.
